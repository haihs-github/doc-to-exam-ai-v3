# Handoff M1 - 12/11/2026

Nhánh `m1/auth` (đã gồm merge `m1/api` và `m1/web`). Không đụng `main`, `m0/*`; chưa push.

## Đã làm
- API: `POST /api/auth/{teacher,student}/{register,login}`, `GET /api/auth/me`, `PUT /api/auth/api-key`, `POST /api/auth/logout-all`, `POST /api/auth/change-password`; JWT thu hồi (tokenVersion), RBAC, `secureField` AES-GCM cho Gemini key, bcrypt có cổng đồng thời, rate limit RAM (`RATE_LIMIT_<TÊN>_MAX`), MongoDB in-memory cho dev/test, `instrumentation.ts` fail-fast ở production.
- Web: router + guard, `AuthService`, UI kit, các trang `/about`, `/login`, `/register`, `/teacher/login`, `/teacher/register`, `/change-password`, `/session-error`, navbar (nút API Key, đăng xuất có xác nhận), `ApiKeyModal`, `/` là `HomePlaceholder` khi đã đăng nhập.
- Task 14: prettier 3 file M1 (`e250cbe`), smoke chuyển sang `/about` (`aedad7b`), `e2e/auth.spec.ts` 9 kịch bản (`6cb0930`), env E2E cho API webServer (`9a60dfe`), CI cache binary MongoDB (`904aa96`), About/.env.example/README (`70d0b0d`, `68b597b`, `c4a6299`), CHANGELOG và handoff này.

## Cách chạy
```bash
npm install
npm run dev                                   # API 3000 + web 4200; không đặt MONGODB_URI thì dùng DB in-memory
scripts/limited.sh npx playwright install chromium   # lần đầu
scripts/limited.sh npx playwright test        # smoke + auth, tự khởi động 2 server
```
Giáo viên đầu tiên: đặt `TEACHER_SECRET_KEY` rồi đăng ký ở `/teacher/register` (xem README). Lần chạy E2E đầu tải binary `mongod` (timeout API 240 giây).
